01

Commerce · AI

Mira

A catalogue-led commerce experience with inventory-aware assistance.

Live product ↗ miraapp.com.ng ↗ Source code ↗

Context

Product discovery and customer questions need to stay grounded in a merchant’s catalogue and stock.

Approach

Pair a managed catalogue and conversational product discovery with explicit boundaries between merchant administration and customer chat.

Selected build detail

Next.js App Router, TypeScript, Supabase, Gemini and Groq; catalogue CRUD, stock-aware answers, multilingual support, fuzzy search, manual order tracking, and Paystack. Admin access uses session-bound Supabase RLS; chat uses a service-role path scoped by business_id.

Trade-off

Service-role access bypasses database RLS, so tenant isolation depends on enforcing business_id on the chat path; admin operations remain session- and policy-bound.

Context
