01 / Live product Multi-tenant AI representative

Mira

An AI online representative for commerce, built to answer product questions and support customer journeys with catalogue and stock context.

Open live app ↗ Visit miraapp.com.ng ↗

Problem

Provide an online representative that can respond to shoppers using each business's product catalogue and available stock context.

Constraints

The product is multi-tenant, supports multilingual interactions and fuzzy search, and includes both automated answers and manually tracked orders.

Approach

Built with Next.js App Router and TypeScript, Supabase Postgres and Auth, and Gemini with Groq as a fallback. Implemented product catalogue and admin CRUD, stock-aware answers, multilingual support, fuzzy search, manual order tracking, and Paystack payments.

Outcome

Implemented the described commerce assistant and supporting admin and payment capabilities. No measured results were supplied.

Technology: Next.js App Router · TypeScript · Supabase Postgres/Auth · Gemini · Groq · Paystack

02 / Orchestration Multi-model system

Vanta

A multi-model orchestrator combining browser automation, a watcher daemon, keyword-based retrieval, and a live web interface.

Project details available on request

Problem

Bring multi-model orchestration and browser-based automation together in one system.

Constraints

The implementation combines browser tasks, a watcher daemon, keyword RAG, and a Flask/Socket.IO interface.

Approach

Implemented the orchestrator in Python with Flask, used Playwright for browser automation, and connected the watcher daemon, keyword RAG, and Flask/Socket.IO UI.

Outcome

The described orchestration, browser automation, watcher, retrieval, and interface components were implemented. No measured results were supplied.

Technology: Python · Flask · Playwright · Flask/Socket.IO · keyword RAG
